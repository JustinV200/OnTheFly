# Frontend

Local React + Vite frontend for the spend-transparency marketplace demo.

## Setup

```bash
cd frontend
npm install
cp .env.example .env
```

## Environment

- `VITE_API_URL` — backend base URL, defaults to `http://localhost:8000`

## Start dev server

```bash
cd frontend
npm run dev
```

## Build

```bash
cd frontend
npm run build
```
